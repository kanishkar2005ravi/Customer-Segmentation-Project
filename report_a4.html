DATE:		 MINI PROJECT - Mall Customer Segmentation

Aim:

To develop a machine learning-based Mall Customer Segmentation System that analyzes customer demographic and spending parameters to identify different customer behavioral clusters using unsupervised learning and Retrieval-Augmented Generation (RAG).

Define:

The problem is to develop a machine learning application that uses customer-related parameters such as Age, Gender, Annual Income, and Spending Score to identify distinct customer personas. The system should also use Retrieval-Augmented Generation (RAG) to provide understandable contextual retail insights, personalized promotion recommendations, and customer retention strategies.

Problem Statement

"How might we develop a machine learning application that uses customer demographic and spending parameters to identify distinct customer behavioral segments and provide an understandable, actionable retail promotion strategy to store managers using Machine Learning and RAG?"

Existing Problems

  • Manual categorization of high-volume customer transaction records is tedious and time-consuming.
  • Multiple customer attributes such as Age, Annual Income, and Spending Score are difficult to correlate manually. Subtle behavioral spending clusters are not obvious from individual variables.
  • One-size-fits-all generic discount campaigns result in low customer conversion and marketing budget waste.
  • Different income groups possess contrasting shopping motivations (e.g., budget-conscious vs. trendsetters vs. luxury buyers).
  • A standalone machine learning cluster output (e.g., Cluster 0, 1, 2) does not explain the domain-specific promotional strategy or customer retention roadmap.

Objective

  1. Collect customer demographic and spending parameters from a public benchmark dataset.
  2. Preprocess and prepare the customer dataset (handling missing values, encoding, and scaling).
  3. Train suitable unsupervised machine learning clustering models (K-Means, Agglomerative, DBSCAN).
  4. Identify optimal customer segments using the Elbow Method (WCSS) and Silhouette Score.
  5. Compare clustering algorithms using validation metrics (Silhouette, Davies-Bouldin Index).
  6. Predict the customer segment and shopping persona of a new customer record.
  7. Use RAG to retrieve relevant retail marketing, customer loyalty, and promotion knowledge.
  8. Provide an understandable AI-generated explanation of the predicted customer persona.
  9. Develop a web application for dataset upload, clustering studio, prediction, and RAG analysis.

Empathy:

The empathy phase focuses on understanding the difficulties faced by retail store managers and marketing teams when analyzing customer spending habits and designing targeted marketing campaigns.

Problem Understanding

Shoppers generate diverse parameters including age, annual income, and in-store spending frequency. It can be difficult for a store manager to determine whether a customer requires luxury VIP white-glove treatment, Buy-Now-Pay-Later (BNPL) schemes, or family dining vouchers by looking at raw transaction tables manually.

User Needs

  • A simple way to upload customer transaction and demographic data (CSV / JSON).
  • A quick customer segment and persona prediction for new shoppers.
  • Clear cluster profiling (Income range, spending tier, demographic ratios).
  • Clustering model performance information (Silhouette Score, Elbow Curve).
  • Identification of primary spending drivers and cluster centroids.
  • An understandable explanation of the predicted customer segment.
  • Targeted marketing campaign and promotional recommendations using RAG.

Ideate:

During the Ideate phase, possible solutions are considered and converted into a practical machine learning and RAG prototype.

  1. Develop an unsupervised machine learning model for customer behavioral segmentation.
  2. Use a publicly available benchmark dataset (Kaggle Mall Customer Segmentation Data).
  3. Allow users to upload CSV or JSON customer demographic and spending datasets.
  4. Apply data cleaning, validation, and feature distribution profiling.
  5. Handle missing values, encode gender, and normalize numerical features where required.
  6. Compare suitable clustering algorithms (K-Means, Agglomerative Hierarchical, and DBSCAN).
  7. Evaluate clustering quality using Silhouette Score, Davies-Bouldin Index, and Calinski-Harabasz Index.
  8. Determine optimal number of clusters ($K=5$) via the Elbow Method (Inertia minimization).
  9. Develop a RAG knowledge base containing information about retail marketing, VIP concierge, customer retention, BNPL promotions, and discount optimization.
  10. Synthesize personalized promotional offers and channel recommendations grounded in RAG.

Prototype:

The proposed prototype is a Mall Customer Segmentation & RAG Marketing Dashboard developed using Python/TypeScript, Machine Learning, RAG, and a web-based frontend and backend.

The user uploads a customer dataset. The system analyzes available features, preprocesses the parameters, trains clustering models, evaluates cluster separation metrics, and classifies customer personas.

1. Dataset Upload & Profile:

Allows the user to upload a CSV or JSON customer dataset and displays feature statistics.

2. Customer Segment Prediction:

Uses the trained clustering model to predict the customer persona for input demographics.

3. Result Summary:

Displays 2D scatter plots (Income vs. Spending), centroid coordinates, and cluster distributions.

4. Model and RAG Insights:

Displays Silhouette evaluation metrics and retrieves relevant retail marketing knowledge using RAG to explain the predicted persona and recommend targeted campaigns.

Code:

import pandas as pd import numpy as np from sklearn.cluster import KMeans from sklearn.metrics import silhouette_score, davies_bouldin_score # Load dataset data = pd.read_csv("Mall_Customers.csv") # Select features for 2D Clustering X = data[["Annual Income (k$)", "Spending Score (1-100)"]].values # Determine optimal K using Elbow Method (WCSS) wcss = [] for k in range(1, 11): kmeans = KMeans(n_clusters=k, init='k-means++', max_iter=300, random_state=42) kmeans.fit(X) wcss.append(kmeans.inertia_) # Train final model with optimal K=5 model = KMeans(n_clusters=5, init='k-means++', max_iter=300, random_state=42) data["Cluster"] = model.fit_predict(X)
# Model Evaluation sil_score = silhouette_score(X, data["Cluster"]) db_score = davies_bouldin_score(X, data["Cluster"]) print("Optimal Clusters (K):", 5) print("Silhouette Score:", round(sil_score, 4)) print("Davies-Bouldin Index:", round(db_score, 4)) print("Inertia (WCSS):", round(model.inertia_, 2)) print("Cluster Centroids:\n", model.cluster_centers_) # Single customer prediction (e.g., Annual Income=$85k, Spending Score=80) new_shopper = np.array([[85, 80]]) predicted_cluster = model.predict(new_shopper)[0] print("Assigned Cluster:", predicted_cluster)
